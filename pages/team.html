Website Team & Responsibilities

This page lists owners for the website launch and the authentication/session policy (no persistent/"easy" login by default).

Team assignments

  • Alex Morgan — Product Owner: overall coordination and acceptance criteria.
  • Carlos Reyes — Backend Engineer: auth endpoints, session handling (session-scoped tokens), logout behavior.
  • Priya Patel — Frontend Engineer: sign-in UI, forgot-password UI, remove persistent login, ensure sessionStorage is used for auth tokens.
  • Jordan Lee — Security / Privacy Officer: security hardening, privacy review, token policies, audit logging.
  • Taylor Kim — QA Engineer: QA test cases, e2e validation that closing the browser requires re-login.
  • Riley Chen — DevOps / SRE: monitoring and alerts for auth endpoints.
  • Samira Khan — UX / Content Writer: privacy page copy, email templates and user guidance.

Auth policy (summary)

  • No persistent/"easy" login by default — authentication uses session-scoped storage so closing the browser requires re-login.
  • Logout clears session storage immediately.
  • Forgot-password tokens are single-use and time-limited.
  • All auth endpoints must enforce HTTPS, rate limiting and CSRF protections.

If you are listed here and need a different assignment, contact the Product Owner: Alex Morgan.
